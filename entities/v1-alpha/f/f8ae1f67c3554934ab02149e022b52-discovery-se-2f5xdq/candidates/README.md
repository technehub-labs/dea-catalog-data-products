# Discovery service (CSW) of the catalogue of the Community of communes Mayenne Community on "geomayenne.fr"

> This discovery service makes it possible to query the catalog of geographical data and web services of the Community of Mayenne Community municipalities referenced in the platform "geomayenne.fr", via the CSW 2.0.2. This harvesting point makes it possible to discover the description sheets (metadata) of the geographical data disseminated by the Community of Mayenne Communes Community which are concerned by the European INSPIRE Directive or which are of public interest.
