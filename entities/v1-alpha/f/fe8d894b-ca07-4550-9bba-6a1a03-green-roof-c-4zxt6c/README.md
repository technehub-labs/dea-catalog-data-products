# Green roof cadastre NRW

> The "Gründachkataster NRW" informs about the potentials of retrospective green roofing, serves as orientation for owners and provides municipal actors with important basic data for climate adaptation strategies. The data are model results that serve as a non-binding initial information and not exact measurement data. The calculated values may differ from the actual conditions for methodological reasons and are to be understood as orientation. Roof greening can only be carried out after checking the local conditions, in particular the statics. Roof windows and the like cannot be detected. In principle, specialist companies for the subsequent greening of the roof should be commissioned for larger roof sections. If necessary, requirements of the monument protection or local design statutes must be observed.
