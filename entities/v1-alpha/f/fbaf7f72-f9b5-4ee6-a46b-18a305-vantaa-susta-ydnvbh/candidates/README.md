# Vantaa sustainable development indicators

> The file contains the indicators of Vantaa's Voluntary Local Review (VLR). The indicators are based on the Sustainable Development Goals (SDGs) of the UN 2030 Agenda. The indicators in the file include dimensions of ecological, economic, social and cultural sustainability.
