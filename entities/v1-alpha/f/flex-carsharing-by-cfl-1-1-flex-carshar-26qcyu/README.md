# FLEX Carsharing by CFL

> The primary objective here is to provide the list of available FLEX vehicles and to describe the last known station per vehicle. The fields included in this document are as follows: - because _type : Type of car (e.g.: Small Car, Transporter, …) - fuel _type : Fuel type (Ex.:Diesel, Electric, Super petrol) - available : Availability of the car (TRUE) - brand_name : Car brand (e.g. Audi, BMW, VW, Mini, …) - model_name : Car model _name Station : Name of the station _town Station : City/village of the resort _zipcode Station : Postal code of the station _street Station : Station Street _streetnumber Station : Street number of the station _latitude Station : Latitude GPS Point _longitude Station : GPS Point Longitude - createdDate : Date and time of creation of the file GPS coordinates show the exact position of the station, the address may differ from the actual position.
