# Four-thousanders

> At the request of Valais Tourism, this dataset was compiled on the basis of names and elevation data from SwissNames3D, as of 2013. The criteria of the "International Climbing and Mountaineering Association (UIAA)" for the registration were the mountain peaks with a height above 4000m.
