# Open Data Portal Access Statistics - Year 2025

> The dataset collects the statistics relating to accesses made on the Open Data portal for the year 2025, with specific reference to the individual datasets published. For each dataset there are key information such as the total number of views and downloads, as well as other useful information such as the title, the dates of creation and last modification, the version etc. This dataset allows to analyze the degree of interest and involvement of users with respect to the content available on the portal, favoring evaluations on the impact and use of open data by the community.
