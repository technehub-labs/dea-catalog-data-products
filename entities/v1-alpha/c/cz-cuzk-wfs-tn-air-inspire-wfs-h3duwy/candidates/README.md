# INSPIRE WFS Download service for the theme Transport Networks-AIR (TN_AIR)

> The INSPIRE Download Service for the Transport Networks – AIR (TN_AIR) theme is a service that allows users to repeatedly download data using WFS 2.0.0 technology. The download service provides harmonised INSPIRE data for the Transport Networks – AIR (TN_AIR) theme, corresponding to the INSPIRE XML schema version 4.0 and the ELF XML schema version 1.0. Data are provided in GML 3.2.1 format. This dataset of transport networks of the Czech Republic therefore has a unified structure with other data created for this INSPIRE theme across Europe. The basis of the dataset is the Fundamental Base of Geographic Data of the Czech Republic (ZABAGED®). The service complies with the Technical Guidance for the Implementation of INSPIRE Download Services, version 3.1, and also with the OGC Standard for WFS 2.0.0.
