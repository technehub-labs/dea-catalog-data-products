# PMI76 Childcare 2018a2023 dec2024

> This file presents the data relating to the reception of children in Seine-Maritime, by Territorial Unit of Social Action (UTAS) and by year, from 2018 to 2023. It should be noted that activity in 2020 and, to a lesser extent, 2021 was impacted by successive COVID lockdowns. In addition, the 2022 data collection was impacted by the IT attack on the Department in October 2022 (hence many "undetermined" (ND) mentions). Data on childcare include the number of family assistants, the number of maternal assistants, the number of nursing homes (MAM), including new ones created in the year, the number of childcare facilities, including new ones created in the year, and the capacity of each of these categories according to their approvals.
