# Vegetation cover estimates and sediment records for Gåsfjärden and Lake Storsjön, Sweden

> Datasets of vegetation cover estimates in percentage from Gåsfjärden and Lake Storsjön based on the Landscape Reconstruction Algorithm and the lignin phenols records of the sediment cores from Lake Storsjön and Gåsfjärden. For a more detailed description of the methodology, see Yang, B., Ljung, K., Ning, W., Filipsson H.L., Nielsen, A.B. Relationships between land use and terrestrial organic matter transfer to the Baltic Sea over the last 500 years. JGR Biogeosciences, Submitted.
