# Spring frost indicators and underlying data

> The data set contains indicators related to future spring frost occurrence in Fennoscandia. The indicators were calculated from the daily average and daily minimum air temperature data from the regional climate model simulations from the CORDEX-CMIP5 project. These climate model simulations have previously been bias-adjusted to minimise systematic errors, as described in the included documentation, and use Representative Concentration Pathways RCP2.6, RCP4.5, and RCP8.5. The indices follow the conventions of the Climix tool and comprise: - start of growing season [gsstart], - last spring frost [lsf], - number of spring frost days [fdgsstart], and - late frost lag since vegetation onset [lflsvo] The indices are given as NetCDF files with yearly time-resolution and a spatial grid spacing of approximately 12.5x12.5km, one file for each index/GCM/RCM/RCP combination. Ensemble averages are also included, one file for each index/RCP combination. The underlying bias-adjusted gridded daily average near-surface air temperature and daily minimum near-surface air temperature data are also included, one file for each GCM/RCM/RCP combination.
