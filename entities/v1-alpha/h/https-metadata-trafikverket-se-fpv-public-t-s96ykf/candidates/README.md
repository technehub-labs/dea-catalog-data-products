# FPV public transport

> FPV Public transport is a function of the road network FPV (Functional Priority Road Network). FPV Public transport points to the roads that are important for public transport such as priority routes, core lines with frequent bus traffic that the regional public transport authorities have identified, and more long-distance bus lines.
