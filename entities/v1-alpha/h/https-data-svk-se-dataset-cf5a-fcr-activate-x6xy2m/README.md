# FCR Activated Energy 60 min (Discontinued, please read description)

> **This dataset is no longer updated.** The presented data includes activated energy in MWh of FCR balancing energy from Swedish providers of ancillary services (BSPs). The presented prices refer to the balancing price (EUR/MWh). For FCR-D Down, data is only available from after December 2021. For further information, please see: [Information on different ancillary services](https://www.svk.se/en/stakeholders-portal/electricity-market/provision-of-ancillary-services/information-on-different-ancillary-services/) For further information in *Swedish*, please see: [FCR-N, Frequency Containment Reserve - Normal](https://www.svk.se/aktorsportalen/bidra-med-reserver/om-olika-reserver/fcr-n/) [FCR-D Down, Frequency Containment Reserve - Disturbance Down regulation](https://www.svk.se/aktorsportalen/bidra-med-reserver/om-olika-reserver/fcr-d-ned/) [FCR-D Up, Frequency Containment Reserve - Disturbance Up regulation](https://www.svk.se/aktorsportalen/bidra-med-reserver/om-olika-reserver/fcr-d-upp/)
