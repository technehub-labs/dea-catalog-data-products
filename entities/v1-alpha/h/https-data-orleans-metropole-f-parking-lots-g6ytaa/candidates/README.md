# Parking lots - Orléans Métropole

> List of Orléans Métropole car parks (parkings, bus relay car parks and tram relay car parks), with mention of the places available in real time for parks equipped with an access control system. **This data can be viewed here:<https://data.orleans-metropole.fr/pages/mobilite-automobile/>** This dataset conforms to the national scheme <https://schema.data.gouv.fr/etalab/schema-parking/0.1.5/>[](https://schema.data.gouv.fr/etalab/schema-parking/0.1.5/documentation.html#property-type-users) Compared to the national scheme, the following columns have been added: * name of the manager * type of car park: car park / bus relay car park / tram relay car park * real-time availability of parking spaces: yes / no * number of places available => **this data is updated every 5 minutes** * availability rate * condition of the car park (closure for works, etc.), resulting from the equipment repository <https://data.orleans-metropole.fr/explore/dataset/om-territoire-equipements/>
