# Normandy Region Grants 2021

> Following the publication of [Decree No 2017-779 of 5 May 2017](https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000034600552#:~:text=Dans%20les%20r%C3%A9sum%C3%A9cret%20n%C2%B0%202017%2D779%20du%205%20mai%202017%20relative,essentielles%20des%20conventions%20de%20subvention&text=Publics%20concern%C3%A9s%20%3A%20administration%20de%20l,une%20mission%20de%20service%20public.) relating to access in electronic form to the essential data of the grant agreements and the [Decree of 17 November 2017](https://www.legifrance.gouv.fr/loid/JORFTEXT0000408/52) on the conditions for making these data available, the Normandy Region publishes data on grants subject to a signed agreement. The Order also describes all [fields] (https://www.legifrance.gouv.fr/loda/id/JORFTEXT000036040528/). The game follows the scheme of the Common Core of Local Data. The following fields have been added by the Normandy Region: * numberPayments: Number of grant payments * locationCodeINSEE: INSEE code of the locality municipality of the project * Community project location: Name of the localization municipality of the project * TypeThird: Legal nature of the beneficiary * DateDecision: Date of decision This dataset includes all grant agreements of €23,000 or more awarded in **2021**. **No update planned.**
