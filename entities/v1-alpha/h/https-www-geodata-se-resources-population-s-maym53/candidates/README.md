# Population statistics on km-box

> Population statistics per km square (1x1 km). Data includes total population, gendered and 5-year classes. The statistics are available from 2015-12-31 to 2025-12-31. National data not INSPIRE. Statistics for several years and with other groupings can be ordered from Statistics Sweden on a commission basis.
