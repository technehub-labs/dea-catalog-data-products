# Statistics on tourists visiting the Vilnius Tourism Information Centre (Pilies str. 7)

> The package contains statistics on tourists visiting the Vilnius Tourism Information Centre (Pilies Street 7) for the day from 2015 to 2023. The object of the package is aggregated monthly data according to the country and/or region of the tourist who visited the centre and the method of providing consultations (by phone or email). Contact the atverimas@stat.gov.lt for technical questions or possible errors.
