# Health map of the Valencian Community

> Information corresponding to the territorial organization of the health map based on population, sociocultural, etc... This information consists of a file in .csv format available in this same data set and a series of cartographic layers in shapefile and json format that are accessible through the following URLs: - 1.Data for **[departments of health](https://dadesobertes-tsa.gva.es/dataset/health-sip-departments-health)** - 2.Data for **[auxiliary consultancies](https://dadesobertes-tsa.gva.es/dataset/sanidad-sip-consultorios-aux)** - 3.Data for **[health zones](https://dadesobertes-tsa.gva.es/dataset/sanidad-sip-zonas-salud)** of the Valencian Community - 4.Data for **[census sections](https://dadesobertes-tsa.gva.es/dataset/health-sip-census sections)** - 5.Data for **[municipalities](https://dadesobertes-tsa.gva.es/dataset/health-sip-municipalities)** - 6.Data for **[hospitals](https://dadesobertes-tsa.gva.es/dataset/health-sip-hospitals)** - 6.Data for **[census districts](https://dadesobertes-tsa.gva.es/dataset/sanidad-sip-districts-censales)** - 8.Data for **[health centres](https://dadesobertes-tsa.gva.es/dataset/health-sip-health centres)** - 9.Data for **[specialty centres](https://dadesobertes-tsa.gva.es/dataset/health-sip-specialty centres)**
