# Environmental monitoring sites: Data hosting Agricultural land

> Within the farmland data hosting, results from monitoring of nutrients, plant protection products, analyses of soil samples, and soil compaction in agricultural land, among other things, are managed. It is mainly the results of ongoing surveys that are stored and managed in the farmland data hosting. Sites for sampling are registered together with measurement data in the database of the Swedish University of Agricultural Sciences (SLU) and in the Stations Register, which is a single national register of facilities (stations, test sites) where environmental monitoring is carried out.
