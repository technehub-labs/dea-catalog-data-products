# FPV Freight Transport

> FPV freight transport is a function of the road network FPV (Functional Priority Road Network). FPV freight transport identifies roads that are internationally, nationally and regionally important for long-distance freight transport, as well as roads with links to nationally and regionally important nodes. The identified routes create a coherent regional and national network with links to key target points and nodes.
