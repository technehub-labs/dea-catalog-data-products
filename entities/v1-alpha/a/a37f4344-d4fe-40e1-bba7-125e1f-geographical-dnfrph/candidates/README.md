# Geographical coordinates of educational establishments (geocoding)

> The data set includes the geographical coordinates of the pre-university education units, from the school network 2016-2017, geocoded based on the postal address. DISCLAIMER: Since Romanian postal addresses cannot always be geocoded correctly, the dataset may contain inaccuracies or missing coordinates. The aim of the publication is to refine these coordinates with the help of civil society.
