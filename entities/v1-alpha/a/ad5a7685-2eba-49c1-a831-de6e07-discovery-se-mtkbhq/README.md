# Discovery service (CSW) of the catalog of the Public Geographic Information Platform Nord-Pas de Calais

> This discovery service makes it possible to query the catalogue of geographical data and web services of the Public Geographic Information Platform Nord-Pas de Calais referenced on the portal [PPIGE] (http://www.ppige-npdc.fr/portal/), via the CSW 2.0.2. This harvesting point makes it possible to discover the metadata of the geographical data disseminated by the PPIGE concerned by the European INSPIRE directive or of public interest.
