# Zurich Overnight Visitor Logs ("Nachtzedel") 1780-1792: Digitized Copies

> This dataset contains JPEG scans of the Zürcher Nachtzedel (Zurich Overnight Visitor Logs). Similar to the _Fremdenlisten_ or _Fremdenblätter_ found in other cities, these records document individuals and groups who stayed overnight in Zurich's hotels and inns. By recording personal details of the travelers, such as name, places of origin, and professions, they provide unique insights into travel patterns and mobility in the late eighteenth century. The dataset comprises all currently digitized records spanning eleven years: 1780, 1781, 1782, 1783, 1784, 1785, 1787, 1788, 1790, 1791, 1792. A structured dataset in JSON and CSV formats, comprising transcriptions and standardized information derived from these records, is available on Zenodo: [Zurich Overnight Visitor Logs (Nachtzedel) 1780-1792: Extracted Data](https://doi.org/10.5281/zenodo.18845078)
