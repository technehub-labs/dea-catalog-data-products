# Bolvir healthy itineraries network

> Bolvir healthy itineraries network is a set of cartographic data that provides information on Bolvir healthy itineraries, the location of the urban health park and a link to the Healthy Itineraries Network that leads to a page where you can see a map. or interactive satellite image with various routes from which you can know its location, length and height profile. It also has a guide of tips and recommendations for completing the itineraries.
