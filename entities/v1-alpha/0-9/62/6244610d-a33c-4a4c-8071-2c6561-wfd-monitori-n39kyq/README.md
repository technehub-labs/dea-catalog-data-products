# WFD Monitoring sites (INSPIRE harmonised)

> Inspire harmonised dataset of the national monitoring sites file in WFD surface water bodies and WFD groundwater bodies. This file contains all monitoring sites reported to the EU under the Water Framework Directive for both groundwater and surface water. These are monitoring sites that at some point in time are the monitoring sites that have been used for the status determination for the current WFD planning period. A selection of these monitoring sites have been used for the WFD monitoring programme.
