# Phenological observations - Data

> The Swiss phenology network consists of 175 stations. Some 26 different plant species are observed in order to describe the vegetation development. On the basis of this information, it is possible to investigate the impact of climate change on the vegetation. The observations also serve to generate forecasting models for the start of blooming. The data set contains for each station and plant species phenophases in yearly ('y') resolution.
