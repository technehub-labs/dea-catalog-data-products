# Citymapper mobility index

> Extraction of raw data published by Citymapper at https://citymapper.com/CMI ## Description of the data We are comparing trips planned in the Citymapper app to a recent typical use period. Trips planned (‘Get me somewhere’ and related) are correlated to trips taken (GO mode). We have enough data in our cities where we publish CMI to be confidant that it represents a real change.
