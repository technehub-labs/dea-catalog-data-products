# NEOLAiA - International Mobility OUTGOING ay 2023-2024

> This dataset includes outgoing mobility data provided by all NEOLAiA partner universities. It was created by merging individual outgoing datasets supplied by each partner institution into a single comprehensive dataset, resulting in a total of 1,108 rows. The dataset provides detailed information on Erasmus+ and international outgoing student mobility flows for the academic year 2023–2024, including information on home and host universities, study programs, course types, gender, citizenship, ISCED classification, and the specific academic activities carried out abroad (exams, thesis, internship, or combinations of these).
