# NEOLAiA - International Mobility INCOMING ay 2023-2024

> This dataset includes data from all NEOLAiA partner universities. It was created by merging the individual datasets provided by each partner into a single comprehensive dataset, resulting in a total of 1,167 rows. The dataset provides detailed information on Erasmus+ incoming student mobility flows for the academic year 2023–2024, including data on home and host universities, countries, gender, study cycle, mobility period, and associated departments.
