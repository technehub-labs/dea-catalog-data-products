# Pedestrian Footfall DLR

> Pedestrian footfall counts at a number of locations within the Dún Laoghaire-Rathdown County Council administrative area. Pedestrian counts are available from seven locations throughout the county, each of which records bidirectional pedestrian traffic. Data is provided in hourly intervals (i.e. the data at 11:00 am corresponds to the counts saved between 11:00 am and 12:00 am). Data gaps are due to a pedestrian counter fault or due to a battery requiring replacement
