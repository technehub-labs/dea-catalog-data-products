# REA 2008 - State of the Environment Report 2008

> The State of the Environment Report now presented (SER 2008), based on 33 key indicators, seeks offer a comprehensive picture of the state of the environment over the past few years, with a particular focus on 2008. At a time when more and more information is available, in various forms, it is essential that disclosing processed, perceptible and synthetic data to facilitate their analysis and understanding. In this way, and following the methodological options initiated with SSA 2004, SSA 2008 starts a second series of reports synthetics, as in the SSAs for 2004, 2005 and 2006. Key indicators serve the purpose of to summarise in a few simple or composite indicators the main trends in the various environment or, in a broader sense, the sustainable development of the country.
