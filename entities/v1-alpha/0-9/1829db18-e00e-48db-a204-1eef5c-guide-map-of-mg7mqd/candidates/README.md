# Guide map of the Helsinki metropolitan area

> The guide map of the Helsinki Metropolitan Area is a map of the area with a generalised documentation technique, produced to assist in positioning and guidance. The guide map is produced from the guide map data maintained by the municipalities in the Helsinki Metropolitan Area by combining different data into a single map. The data is merged by the City Survey Services of the City of Helsinki Urban Environment Division. The guide map of the Helsinki Metropolitan Area covers the areas of the cities of Helsinki, Espoo, Vantaa and Kauniainen. The dataset is produced with the help of the base map, address decisions, legally valid detailed plans, aerial photographs and other data sources. The data is constantly updated. An open data publication is carried out once a year. The guide map contains the following information: place names, streets, roads and railway connections, public buildings, areas with blocks of flats, detached house areas, industrial areas, forest and field areas, nature reserves and municipal boundaries. In addition, the map shows the names of the city districts and city sub-districts, as well as some attractions and public services. The nominal scale of the dataset is 1:10,000. The guide map of the Helsinki metropolitan area is published as a raster image file in the TIF file format. The raster image is positioned in the coordinate system using the TFW and TAB files. **Detailed description of the dataset:** - https://kartta.hel.fi/opendata/documents/PKS_opaskartta_ description.pdf (in English) - https://kartta.hel.fi/geographic directory/pth/?id=188 (in English) **Previewing the data in the map.hel.fi service:** - [Guide map (metropolitan area](https://kartta.hel.fi/link/0eyU2sm) - [Guide map (metropolitan area, grey)](https://kartta.hel.fi/link/dMLC4J) - All base map layers can be found on the website: [https://kartta.hel.fi/](https://kartta.hel.fi/?setlanguage=en) > Layers > Background Maps > Guide Maps **Coordinate systems:** - Maintained in ETRS-GK
