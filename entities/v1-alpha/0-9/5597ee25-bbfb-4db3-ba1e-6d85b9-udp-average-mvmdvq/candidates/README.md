# UDP - Average tourism expenditure

> This indicator measures the average economic value generated per night spent at the tourist destination, revealing tourism contribution to the economy of the destination country. The average tourism expenditure was adjusted taking into account the living costs of each country (Parity Purchasing Standards, PPS). Higher values indicate higher average tourism expenditure per each night spent. This indicator is part of the socio-economic pillar This indicator is part of the socio-economic pillar of the EU Tourism Dashboard. UNIT OF MEASURE: PPS / nights spent. RESOLUTION: NUTS0. COMPLETENESS: 100% for EU27 (missing CH, IS, NO). METHODOLOGY: The average tourism expenditure was adjusted taking into account the living costs of each country (Parity Purchasing Standards, PPS). DATA SOURCES: ESTAT (tour_dem_extotw).
