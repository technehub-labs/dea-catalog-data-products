# Pre-1940 Rainfall data

> The data contained in this resource consists of rescued rainfall data from 114 locations across Ireland. The data covers a range of periods pre-1940. Each folder comprises of a csv file with an accompaning metadata text file. The metadata provides a discription of the data, period covered and additional information to support the use of this data.
