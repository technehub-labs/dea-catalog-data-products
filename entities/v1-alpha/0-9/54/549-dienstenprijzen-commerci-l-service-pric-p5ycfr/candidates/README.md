# Service prices;commercial services and transport,2015=100,2002-2023

> This table shows the price indices, quarterly and annual changes in the prices of services provided by commercial services and transport companies. A breakdown is made by service types according to the European Coordinated Classification of Products by Activity (CPA 2008). For some services, a further subdivision has been made based on market data that are different from the CPA. This subheading is denoted by a letter after the CPA code. The price indices in this table all have the index reference year 2015. The annual average, quarterly and annual changes were calculated on the basis of unrounded indices. Data available from: 2002 4th quarter to 2023. Frequency: quarterly Status of figures: The data is final. Changes as of 17 May 2024: None, this table has been discontinued. When will there be new figures? No longer applicable. This table has been discontinued as of 17 May 2024 and continued as Service Prices; commercial services and transport, 2021=100. See paragraph 3. The publication schedule Service prices can be downloaded as an Excel file under paragraph: 3 Relevant articles. More information about the pricing method can be found in the video under section: 3 Relevant articles.
