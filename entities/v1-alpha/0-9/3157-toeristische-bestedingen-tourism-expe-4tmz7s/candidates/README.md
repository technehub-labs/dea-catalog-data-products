# Tourism expenditure 2005 - 2012

> This table contains data on tourism spending. Tourism is not an industry in itself, but covers a large number of products and services supplied to tourists from different industries. The figures are consistent with the conceptual framework of the National Accounts (NR) and can be compared with pre-existing macroeconomic indicators such as gross domestic product, total value added and total number of jobs in the Netherlands. The tourism accounts thus provide an integrated macroeconomic overview of the significance of tourism for the economy. Data available from: 2005 to 2012 Status of figures: The figures up to 2010 are final, the figures for the years 2011 and 2012 are (further) provisional.
