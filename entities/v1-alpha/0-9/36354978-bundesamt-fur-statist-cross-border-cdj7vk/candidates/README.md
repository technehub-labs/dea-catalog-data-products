# Cross-border city statistics: Demography (Agglomerations 2020)

> This dataset presents annual data for a selection of variables of cross-border city statistics concerning the demographics according to the version 2020 of the agglomerations (permanent resident population, youth quotient, age quotient, median age, population density, population shares of the Swiss and foreign populations), from 2020 onwards.
