# Bicycle Counts DLR

> Bicycle traffic volumes from cycle counters in Dún Laoghaire-Rathdown County Council administrative area. Bicycle counter data is available from sixteen locations throughout the county. Ten of these locations record bidirectional traffic, with the remaining six recording unidirectional cycle traffic. Data is provided in hourly intervals (i.e. the data at 11:00 am corresponds to the counts saved between 11:00 am and 12:00 am). Data gaps are due to a cycle counter fault or due to a battery requiring replacement
