# Environment Vision 2018 — Bus line base

> Version of Buslijn base adopted by Provinciale Staten van Drenthe on 3 October 2018. With the basic lines we offer bus connections from the rural area to the regional centres, regional railway lines and HOV bus lines. For the baselines, the connection between the relevant chain nodes is guaranteed, but the route and also the stops can change. The modification of routes or stops is, of course, done in coordination with the responsible road operators. Map Mobility
