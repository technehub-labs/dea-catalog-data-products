# UDP - Accommodations listed online

> This indicator is a proxy for the online presence of the tourism accommodation capacity. It relates the observed number of tourist accommodation rooms (in hotel and short-term rentals) listed on a key web platform (TripAdvisor) with the expected number of listed number of rooms given known tourism demand. The expected number of listed rooms is derived from a linear regression between supply (no. of rooms) and tourism demand (no. of nights spent) for all EU countries. The indicator values are the percentage difference between the expected and observed number of listings per destination. This indicator is part of the digital pillar of the EU Tourism Dashboard. UNIT OF MEASURE: %. RESOLUTION: NUTS0. COMPLETENESS: 100%. POLICY CONTEXT: Low values indicate a lower than expected online presence in relation to the recorded tourism demand. METHODOLOGY: The formula derived from linear regressing ESTAT nights spent and web scraped TripAdvisor accommodations, is used to compute the expected TripAdvisor accommodations. This indicator is calculated by the percentage difference between the expected and actual TripAdvisor accommodations. DATA SOURCES: TripAdvisor; Eurostat (tour_occ_nim).
