# SVK International Mobility INCOMING ay 2023-2024

> This dataset contains all the information needed about the incoming international students who are enrolled in the exchange program at Šiauliai State University of Applied Sciences during the 2023-2024 academic year. The data includes information about student demographics, their academic backgrounds, how long they stayed, and which departments hosted them at the university.
