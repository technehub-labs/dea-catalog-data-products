# INSEE- Housing, individuals, activity, school and occupational mobility, residential migration in 2019 – Zone C

> The database “Housings, Individuals, Activity, School and Work Mobility, Residential Migration in 2019 Census of Population – Detail File” contains detailed data from the Census of Population in France in 2019. It is intended for professional users for in-depth analysis and behavior modelling. The data is anonymised to protect privacy, and it is presented in the production geography as of January 1, 2021. This database brings together the Grand Est regions (region 44), Pays de la Loire (region 52) and Brittany (region 53).
