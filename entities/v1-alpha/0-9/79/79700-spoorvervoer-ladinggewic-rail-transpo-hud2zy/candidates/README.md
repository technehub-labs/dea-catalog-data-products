# Rail transport; payload weight, payload tonne-kilometres, train-kilometres

> This table provides data on the transport performance of freight trains across the territory of the Netherlands, with the exception of private railway lines. It concerns domestic transport, supply, disposal and transit. The figures shall include the cargo weight transported, the cargo tonne-kilometres and the train-kilometres travelled. The figures are available as of 2024, as new sources have become available as of that year. This has improved the quality of the figures. Data available from: Figures available from 2024.
