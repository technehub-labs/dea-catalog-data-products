# OpenStreetMap: Tourism - polygons

> This dataset provides daily extraction of OpenStreetMap data flows relating to tourism infrastructure and services in the regions of Provence-Alpes-Côte d’Azur, Occitanie, Auvergne-Rhône-Alpes and the border regions in Italy: Liguria, Piedmont, Aosta Valley. The data extracted concern the map elements associated with OpenStreetMap's **tourism** key, which describes **tourist places and facilities such as hotels, campsites, museums, monuments, tourist offices, natural attractions, cultural sites, and other points of interest for visitors.** The specifications followed are those described in the OpenStreetMap documentation: [🔗 wiki.openstreetmap.org/wiki/EN:Key:tourism](https://wiki.openstreetmap.org/wiki/EN:Key:tourism) Data is processed and extracted using the SQL script available in the DataSud GitLab repository: [🗃_ tourism.sql](https://gitlab.datasud.fr/projects_publics/openstreetmap4datasud/-/blob/main/sql/tourism.sql?reftype=heads) [© OpenStreetMap contributors.](https://www.openstreetmap.org/copyright)
