# OpenStreetMap: Cable part transport - points

> This dataset provides daily extraction of OpenStreetMap data flows relating to cable transport infrastructure in the regions of Provence-Alpes-Côte d’Azur, Occitanie, Auvergne-Rhône-Alpes and the border regions in Italy: Liguria, Piedmont, Aosta Valley. The data extracted concern the map elements associated with OpenStreetMap's **aerialway** key, which describes ski lifts such as chairlifts, cable cars, cable cars, funiculars, etc. The specifications followed are those described in the OpenStreetMap documentation: [🔗 wiki.openstreetmap.org/wiki/Key:aerialway](https://wiki.openstreetmap.org/wiki/Key:aerialway) Data is processed and extracted using the SQL script available in the DataSud GitLab repository: [🗃ц aerialway.sql](https://gitlab.datasud.fr/projects_publics/openstreetmap4datasud/-/blob/main/sql/aerialway.sql?ref_type=heads) [© OpenStreetMap contributors.](https://www.openstreetmap.org/copyright)
