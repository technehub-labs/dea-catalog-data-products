# Digital landscape model - Transport Cut-off date 25.10.2022

> The object area DLM - Traffic comprises the following elements for Austria in the form of high-precision vector graphics with attributes as the basis for geographic information systems: all roads; all railways; Lifts. In addition, the coordinative reference points are also covered with attributes of traffic objects. This is an Austria-wide, high-precision location of POI (points of interest) in the areas of railways, air traffic, shipping traffic, facilities and structures for traffic, transport, communication and supply.
