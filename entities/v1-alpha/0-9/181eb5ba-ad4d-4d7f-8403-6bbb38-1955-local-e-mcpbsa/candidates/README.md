# 1955 Local elections- election statistics

> This document sets out the following statistics for the 1955 local elections: i) the total number of electors nationwide, the number of electors in contested areas and valid votes at the elections. It also sets out the Urban Districts Councils and Town Commissioners where no elections were held or contested. ii) The number of local electors, valid poll and percentage poll for elections in the County Council and County Boroughs elections. iii) The number of local electors, valid poll and percentage poll for elections in the Boroughs and Urban District Council elections. iv) The number of electors, valid poll and percentage poll for elections in the Town Commissioners elections.
