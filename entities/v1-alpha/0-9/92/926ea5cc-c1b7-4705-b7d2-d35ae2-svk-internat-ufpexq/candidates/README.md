# SVK International Mobility OUTGOING ay 2024-2025

> This dataset provides detailed information of outgoing international student exchanges from Šiauliai State University of Applied Sciences during the 2024-2025 academic year. The data includes information about student academic programs, destination institutions and countries, gender distribution, the type of mobility undertaken abroad (semester studies, internships, and Blended Intensive Programmes), and citizenship classifications.
