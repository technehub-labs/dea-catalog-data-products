# Kildare Accessible Parking

> This dataset contains information on the location of accessible parking (adopted through Parking Control Bye-Laws) in Kildare. The data is not representative of all accessible parking spaces in Kildare. The data includes a small number of accessible parking spaces on private property (not adopted through Parking Control Bye-Laws). The dataset was created using KCC data, OSI DigitalGlobe data and Google Street View data. For more information on accessible parking in Kildare, please see the following link: http://www.kildare.ie/CountyCouncil/RoadsandTransportation/Payparking/AccessibleParking/
