# Motor vehicles; demolition, vehicle type, fuel type, 2000-2021

> This table includes Dutch passenger cars and commercial motor vehicles (vans, lorries, semi-trailer tractors, special vehicles and buses) which failed during the reporting year because the registration number/registration certificate was invalidated due to demolition. The vehicles belonging to the demolition are subdivided according to the fuel type of the vehicle. Vehicles that were demolished on 1 January of a given year (for example, on 1 January 2009) were demolished/dismantled in the previous year. These vehicles may have participated in traffic for part of that previous year (for example, in 2008). The data are based on information from the registration of RDW. Data available from: 2000 to 2021 Status of figures: definitively Changes as of 15 September 2022: None, this table has been discontinued. This table is followed by ‘Motor vehicles active; demolition, vehicle type, fuel type’. See paragraph 3 When will there be new figures? Not applicable.
