# Charging infrastructure for electric vehicles (EVRI)

> These data make it possible to locate and know the technical characteristics of stations and recharging points for electric vehicles open to the public, belonging to the Community of Agglomeration of the Pays de Grasse (CAPG) and located in its territory. These stations and charging points are part of the Wiiiz network (more information on the Wiiiz.fr website). This data opening is carried out as part of the implementation of the regulations (Decree 2017-26 of 12 January 2017 on charging infrastructure for electric vehicles (EVRI)....) The dataset includes: • The IRVE_WiiizCAPG_AAAMMJJ.csv file made in compliance with the technical standard required by the regulations
