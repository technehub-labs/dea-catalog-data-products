# SmartBay Ireland Galway Bay Buoy Compass Data

> The CMPS10 Tilt Compensated Compass sensor is a tilt compensated compass which calculates a bearing. Employing a 3-axis magnetometer , a 3-axis accelerometer and a 16-bit processor, the output of the three sensors measuring x, y and z components of the magnetic field, together with the pitch and roll are used to calculate the bearing.
