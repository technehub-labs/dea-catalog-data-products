# Application of PAS 2070: London case study

> <dp-prose> <p>These datasets are for the London case study applying the PAS 2070 British Standard for the assessment of a city&apos;s greenhouse gas emissions. They include:</p> <ul> <li> <p>The full case study datasets</p> </li> <li> <p>Source documentation: A summary of the source data and weblinks where data is publicly available.</p> </li> <li> <p>A verification report: Verifying that the case study is in compliance with the PAS 2070</p> </li> </ul> <p>Link to <a href="https://www.london.gov.uk/what-we-do/mayors-office-policing-and-crime-mopac/community-safety-0/what-we-do/environment/assessing-londons-indirect-carbon-emissions">Executive Summary</a></p> <p>Link to <a href="http://shop.bsigroup.com/Browse-By-Subject/Environmental-Management-and-Sustainability/PAS-2070-2013/">full case study and PAS 2070 Standard</a></p> <p>Source data which is not available publically elsewhere is also published on this page. This includes:</p> <ul> <li> <p>Emissions Factors: &apos;Defra DECC 2012 GHG Conversion factors&apos;, &apos;Aviation Efs&apos;, and &apos;AFOLU&apos;</p> </li> <li> <p>Railways B3: &apos;ORR 2013 Freight Moved&apos;</p> </li> <li> <p>Navigation B3: &apos;DfT 2014 Sea Passengers 2010 London Ports&apos; and &apos;DfT 2014 Sea Passengers 2010 Other Ports&apos;</p> </li> <li> <p>Aviation B3: &apos;FlightGlobal 2013 aviation activity data 2010-2012&apos;</p> </li> <li> <p>AFOLU D1/D2: &apos;R-AEA 2014 AFOLU&apos;</p> </li> <li> <p>Waste E2: &apos;Thames Water Ofwat July 2010 Return&apos;, &apos;Thames Water Ofwat July 2010 Return Calculations&apos;</p> </li> <li> <p>Consumption-Based Methodology: &apos;Leeds University Consumption-Based GHG Emissions of London Final Report&apos; and &apos;Leeds University Consumption-Based GHG Emissions of London Data&apos;</p> </li> </ul> </dp-prose>
