# Hospital District of Helsinki and Uusimaa (HUS) procurements

> The dataset contains information on the purchase invoices of the Hospital District of Helsinki and Uusimaa (HUS). The file is a list of all purchases made by HUS. Each line in the file contains information on the supplier's name and business ID, invoice amount, VAT and date. The information can also be found in the name and number of the responsible unit that made the purchase, as well as in the expense account to which the purchase invoice has been allocated. Sensitive data, i.e. data containing personal data, has been removed from the data.
