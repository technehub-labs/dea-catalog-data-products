# Tracking EU Citizens’ Concerns using Google Search Data

> ‘Tracking EU Citizens’ Concerns using Google Search Data’ offered weekly updates from May to September 2020 on EU citizens’ interests on three main fields related to the pandemic crisis: Health, Economy and Social isolation. The aim is to make Google trends data accessible and useful for policy-makers to better understand EU citizens’ concerns.
