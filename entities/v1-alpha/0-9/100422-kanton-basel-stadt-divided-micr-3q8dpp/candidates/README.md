# Divided micromobility by municipality and day

> The dataset shows the distribution of vehicles from different micromobility providers in Basel-Stadt, broken down by municipality and by day. It contains various statistical figures on the number of vehicles per municipality. The calculation of the dataset is based on the data on the current availability [https://data.bs.ch/explore/dataset/100415/](https://data.bs.ch/explore/dataset/100415/), It is updated every 10 minutes. This means that there is maximum 24 × 6 = 144 Measurements per day for the calculation of the average. The following dataset is used for the municipalities: [https://data.bs.ch/explore/dataset/100017/](https://data.bs.ch/explore/dataset/100017/) An overview of the datasets on shared micromobility can be found at the following link: [https://data.bs.ch/explore/?refine.tags=micromobility](https://data.bs.ch/explore/?refine.tags=micromobility) Note:The data contain a gap between 2 and 22 April 2025 because there was an interruption in the extraction of the data.
