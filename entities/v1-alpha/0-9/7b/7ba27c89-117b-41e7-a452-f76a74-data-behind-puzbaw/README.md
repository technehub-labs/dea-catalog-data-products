# Data behind Energy Scenarios Tool

> This dataset includes the data behind the JRC Energy Scenarios Tool that is available online. The aim of this tool is to explain how energy is produced and used in the EU, today and in the future. The tool helps to understand the magnitude and speed of the projected changes, in other words, to understand the energy transition.
