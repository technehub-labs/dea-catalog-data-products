# Motor vehicles sold new and second-hand; Type of vehicle 2007 - 2016

> This table provides data on the number of new and second-hand motor vehicles sold. This concerns information on passenger cars, commercial motor vehicles and motorcycles. This table does not include data on trailers, semi-trailers and mopeds. Data available from 2007 to 2016. Status of figures: Data from January 2015 to December 2016 are provisional.
