# Guidekarta över Grankulla stad

> The guide map of Kauniainen is a dataset with a generalised position accuracy, which is made to give a wide overview of the entire city and to guide the user to a specific address. The optimum operating scale is 1:20,000. The guide map has been stripped of details, emphasising the importance of the street network, names and addresses. The width of a street depicted on the map does not match the real width of the street. The map covers the area of Kauniainen. A colour guide map is available through the interface. **API addresses:** - WMS API: [https://kartat.kauniainen.fi/teklaogcweb/wms.ashx](https://kartat.kauniainen.fi/teklaogcweb/wms.ashx?request=getCapabilities) **Layers:** - Guide map of Kauniainen
