# Wind: potential wind from before 2009 calculated using the sigma method

> This dataset contains the improved potential wind from 1950 to 2009. This was calculated using the sigma method as described [here](https://cdn.knmi.nl/knmi/pdf/library/knmipubWR/WR2009-02.pdf) and wind measurements describing 10 minute periods. The potential wind in this dataset reveals periods of 1 hour and is the result of a conversion from hourly gustiness analysis potential wind to sigma analysis potential wind. This aggregation step was necessary because the older measurements are hourly.
