# Dignois Urban Transport Network

> Provence Alpes Agglomération organizes, on a day-to-day basis, the Transports Urbains Dignois (TUD). This network serving the City of Digne-les-Bains consists of 4 urban lines (including a doubled line for schools) operating from Monday to Saturday, as well as an on-demand transport service for people with reduced mobility: FlexiTUD.
