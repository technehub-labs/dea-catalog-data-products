# Q_10K_CR36G_TRANSPORT_FUNE

> The Feature Class Q_10K_CR36G_TRASPORTO_FUNE Line geometry at the 1:10,000 scale represents the location of the route of cable transport elements such as cable car, chairlift, cable car, cable car. Derived from the database produced on a scale of 1:5,000 of the multiscale DBTI (Integrated Territorial Database), which provided for the adaptation and structuring, in relation to IntesaGIS standards, of the I and II lot of the CTRN and the subsequent update by means of the photogrammetric resumption of 2007. The geographical information was organised into hierarchical groups, following the model defined in the framework of the State-Regions Agreement on Geographical Information Systems.
