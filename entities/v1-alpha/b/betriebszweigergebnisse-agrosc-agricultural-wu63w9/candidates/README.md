# Agricultural Production-Branch Results

> The dataset contains contribution margin calculations at the farm branch level. The results presented are based on accountancy data. The results from 2016 onwards are based on the ‘Farm Management’ sample (Farm Accountancy Data Network). Results prior to 2016 are based on the ‘Reference Farms’ (Farm Accountancy Data Network). More detailed documentation is contained in the reports. Reports from 2009 up to the most recently published report. The reports for one year always include data for the two preceding years.
