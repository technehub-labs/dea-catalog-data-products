# Archive database of the Swiss Federal Archives

> Metadata of the holdings in the Swiss Federal Archives. The dump contains metadata on 3.84 million dossiers and 257,000 documents that were accessible online in August 2020. This includes over 25,000 preview images. The current database is available in the Linked Data Service (LINDAS): <a href="https://culture.ld.admin.ch/.well-known/dataset/ais?lang=en">Archive database of the Swiss Federal Archives</a>.
