# Wind turbines in the association area of the regional association Greater Braunschweig

> The Regional Association Greater Braunschweig maintains a cadastre for wind turbines in the association area. This spatial data set contains the plant locations including some technical information for the respective plant. The cadastre does not claim to be complete, but is constantly updated and corrected.
