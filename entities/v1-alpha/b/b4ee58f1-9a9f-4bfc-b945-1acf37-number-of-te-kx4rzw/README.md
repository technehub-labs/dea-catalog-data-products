# Number of teachers by position in pre-school educational institutions, general basic and secondary educational institutions, vocational basic and secondary educational institutions and colleges by edu

> Data are displayed for educational institutions of the type "General Education Institution", "Special Education Institution, "Pre-school Education Institution", "Professional Primary and Secondary Education Institution" and "Higher Education Institution" of the type "College". It should also be taken into account that the number of work rates applied to the reference date by the pedagogical staff is more than "0" is shown. The number of pedagogical staff according to the legal address of the educational institution is indicated in the report. For example, for an educational institution whose registered office is in Riga, but which also has a structural unit in Valmiera, pedagogical staff is depicted near Riga. At the same time, it should be noted that if a teacher works in several positions, then he is shown at each of them. Source: State Education Information System (VIIS), operational data. N.B. The structure of the file has been changed since 2024.
