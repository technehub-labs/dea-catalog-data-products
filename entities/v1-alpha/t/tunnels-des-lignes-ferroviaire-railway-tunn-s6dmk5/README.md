# railway tunnels

> This database contains the _tunnels of the _** railway lines of the Luxembourg rail network as defined by the CFL as _**Infrastructure Manager**_. The data are available in _**ESRI Shape**_ format. Data are projected in the national coordinate system **_LUREF (EPSG:2169)_**. The data is also available in _**KML**_ format. The data is then projected in the **_WGS84 (EPSG:4326)_** coordinate system.
