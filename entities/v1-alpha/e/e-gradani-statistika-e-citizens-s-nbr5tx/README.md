# e-Citizens - statistics

> The dataset contains the most interesting statistics of the e-Citizens system. In addition to the number of users of the e-Citizens system, you can find data on the number of e-Citizens by county (by place of residence), which are the most used services and data on the credentials used to access the e-Citizens system.
