# UDP - Average duration of stay

> This descriptor measures the average duration of stays at tourist accommodation establishments. It is calculated by dividing the total number of nights spent by the total number of tourist arrivals. Longer lengths of stay can potentially generate higher tourism expenditure, stimulating the local economy. Higher values indicate a longer average duration of stay. This descriptor is provided in the EU Tourism Dashboard as complementary information to characterize tourism demand. UNIT OF MEASURE: number of days. RESOLUTION: NUTS0, NUTS2. COMPLETENESS: NUTS0: Missing CH for 2020. NUTS2: for 2019 missing NO08, NO09, NO0A, NO0B. For 2020 missing all regions for CH, FR, RO and NO0B. METHODOLOGY: Average duration of stay is obtained by dividing the total number of nights spent by the number of arrivals (nights spent / no. of arrivals). DATA SOURCES: tour_occ_nin2, tour_occ_arn2 [ESTAT]
