# Overview Municipal mobility concepts

> As part of the consultation on the promotion of local authorities for local mobility by NRW.URBAN, the participating municipalities and cities in NRW were asked whether they already have a (near) mobility concept. The data set provided by the Ministry of the Environment, Nature Conservation and Transport of the State of North Rhine-Westphalia provides an overview of municipalities with (near) mobility concepts and municipalities in which a mobility concept is being developed or where it is planned (as of December 2023).
