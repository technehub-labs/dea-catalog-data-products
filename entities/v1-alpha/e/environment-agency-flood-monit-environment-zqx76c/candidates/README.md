# Environment Agency flood-monitoring

> <p>The Environment Agency flood-monitoring API provides developers with access to real time information covering:<br /> •flood warnings and flood alerts<br /> •flood areas which to which warnings or alerts apply<br /> •forecast of flood risks over the next three days<br /> •measurements of water levels and flows<br /> •information on the monitoring stations providing those measurements</p> <p>These APIs are provided as open data under the Open Government Licence with no requirement for registration. If you make use of this data please acknowledge this with the following attribution statement:</p> <p><em>This uses Environment Agency flood and river level data from the real-time data API (Beta)</em></p> <p>For questions on the APIs please contact <a href="mailto:data.info@environment-agency.gov.uk">data.info@environment-agency.gov.uk</a>, a forum for announcements and discussion is under consideration.</p> <p><em>This uses Environment Agency flood and river level data from the real-time data API (Beta)</em></p> <p>More details available at: <a href="http://environment.data.gov.uk/flood-monitoring/doc/reference#introduction">http://environment.data.gov.uk/flood-monitoring/doc/reference#introduction</a></p>
