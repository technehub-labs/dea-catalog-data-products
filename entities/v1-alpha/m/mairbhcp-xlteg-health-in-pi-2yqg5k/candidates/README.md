# Health in pictures

> Health in Image is an easily accessible and interactive website that provides insight into the health, well-being, lifestyle and living environment of Amsterdammers and residents in the Amstelland region. The underlying data are also available and can be downloaded as a file via https://amsterdam.ggdhealthinbeeld.nl/openapi/
