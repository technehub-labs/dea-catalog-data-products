# Mobility - AVL Bus Passenger Counting

> Manual counting of passengers who used the buses of the City of Luxembourg Statistics 2010-2015 - by bus lines - per scheme (AVL/RGTR) ATTENTION: These data refer to the former bus network of the City of Luxembourg. The network was fundamentally changed in 2015-2016. Counts composing this dataset cannot be linked to the new optimized AVL/RGTR network.
