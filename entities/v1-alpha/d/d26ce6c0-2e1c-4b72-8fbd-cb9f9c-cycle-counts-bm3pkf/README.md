# Cycle Counts DCC

> Bicycle traffic volumes from cycle counters in Dublin city. Bike counter include one Totem counter (Grove Road) and Eco-Multi counters using Zelt Diamond loop in a number of other locations. Locations include: Drumcondra, Charleville Mall, North Strand Rd, Guild Street, Richmond Street and Grove Road. Passing cyclists are counted and logged every hour, 24 hours per day, 7 days per week. Data provided by Dublin City Council and the NTA. P.S. Please note that due to ongoing roadworks at Charleville Mall, the repaired counter cannot be reinstalled at present. Reinstallation is expected once the roadworks are completed, currently scheduled until 23.08.2026.
