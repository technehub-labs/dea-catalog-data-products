# Non-motorised transport - Skatingland Schweiz

> “Skatingland Schweiz” from SchweizMobil comprises the national, regional and local skating routes in Switzerland and Liechtenstein. This data set is published in accordance with the Geoinformation Ordinance as part of the geo data set “Cycling networks”. It is compiled in conjunction with the Federal Roads Office, FEDRO, SchweizMobil and the cantons.
