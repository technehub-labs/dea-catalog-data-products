# UDP - Arrivals

> This descriptor measures the total number of arrivals at tourist accommodation establishments in a destination (country or region) in a given year, from both domestic and foreign tourists. Higher values indicate higher tourism demand. This descriptor is provided in the EU Tourism Dashboard as complementary information to characterize tourism demand. UNIT OF MEASURE: number of arrivals. RESOLUTION: NUTS0, NUTS2. COMPLETENESS: NUTS0: Missing CH for 2021. NUTS2: for 2019 missing NO08, NO09, NO0A, NO0B. For 2020 missing all regions for CH, FR, RO and NO0B. For 2021 missing all regions. DATA SOURCES: tour_occ_arm, tour_occ_arn2 [ESTAT].
