# Water Resource Zones

> The Water Resource Zones are a polygon data layer provided by Water Companies in England showing the supply operating boundaries, known as resource zones. These data have been supplied by water companies and collated into a national dataset by the Environment Agency. Attribution statement: Contains Environment Agency information © Environment Agency and/or database rights. Some information used in this dataset is © water companies
