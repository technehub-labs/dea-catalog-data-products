# WEEE Collected UK Summary

> This record is for Approval for Access product AfA312. Contains data reported by Producer Compliance Schemes (PCSs) about the amount of WEEE collected in the UK. The report contains figures for: - WEEE collected from a Designated collection Facility (DCF) - WEEE returned under regulation 32 - WEEE returned under regulation 39 And is broken down by; - Category (1 – 13) - Household/non-household The report is a UK dataset and contains no information about any specific company. Data is reported quarterly. Reports available date back to Q3 2007 Attribution statement: © Environment Agency copyright and/or database right 2019. All rights reserved.
