# INSPIRE - Annex I Theme Transport Networks - Roads - RoadNode

> This dataset contains the road nodes of the Grand Duchy of Luxembourg. The dataset is structured according to the INSPIRE Annex I Theme - Transport networks. The data has been derived from the BD-LTC Database and contains road nodes without further network information.
