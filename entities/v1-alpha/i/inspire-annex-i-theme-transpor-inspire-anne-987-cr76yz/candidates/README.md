# INSPIRE - Annex I Theme Transport Networks - Roads - RoadLink

> This dataset contains the roads of the Grand Duchy of Luxembourg. The dataset is structured according to the INSPIRE Annex I Theme - Transport networks. The data has been derived from the BD-LTC Database and contains road links with the European roads code, the national roads code, the national roads name, the number of lanes, the roads width, the form of ways, the vertical position, the conditions of facility and the functional road classes information.
