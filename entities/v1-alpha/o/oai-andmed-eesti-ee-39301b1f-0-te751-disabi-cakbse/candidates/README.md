# TE751: Disability free life expectancy by sex, age and nationality

> The dataset shows the number of disability free life expectancy by ethnicity (Estonians, non-Estonians), age (0, 65-69), sex and year. The purpose of collecting these data is to provide a standard population health indicator for monitoring trends over time and comparing population groups and regions. Data source: Statistics Estonia
