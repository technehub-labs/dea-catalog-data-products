# Discovery service (CSW) of the catalogue of the Community of communes of the Pays de Craon on "geomayenne.fr"

> This discovery service allows to query the catalog of geographical data and web services of the Community of communes of the Pays de Craon referenced in the platform "geomayenne.fr", via the protocol CSW 2.0.2. This harvesting point makes it possible to discover the description sheets (metadata) of the geographical data disseminated by the Community of communes of the Pays de Craon which are concerned by the European INSPIRE directive or which are of public interest.
