# Discovery service (CSW) of the catalogue of the Communauté d'agglomération Laval Agglomération on "geomayenne.fr"

> This discovery service makes it possible to query the catalogue of geographical data and web services of the Communauté d'agglomération Laval Agglomération referenced in the platform "geomayenne.fr", via the CSW 2.0.2. This harvesting point makes it possible to discover the description sheets (metadata) of the geographical data disseminated by the Communauté d'agglomération Laval Agglomération which are concerned by the European INSPIRE Directive or which are of public interest.
